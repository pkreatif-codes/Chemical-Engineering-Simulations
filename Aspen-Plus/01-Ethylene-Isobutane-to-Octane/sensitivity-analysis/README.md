# Temperature Sensitivity Analysis

This folder contains graphs generated from the Aspen Plus
temperature sensitivity study.

The study investigated reactor outlet temperatures from
60 °C to 140 °C while maintaining the specified conversion
and other fixed simulation conditions.

## Graphs

The graphs examine:

1. N-octane component flow
2. Cooler duty
3. Flash vapour flow
4. Flash liquid flow
5. Reboiler duty

All results are subject to the assumptions and limitations
of the Aspen Plus model.
