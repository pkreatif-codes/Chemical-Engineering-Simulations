# Temperature Sensitivity Analysis

## Overview

This directory contains graphs from the temperature sensitivity study
of the ethylene–isobutane to n-octane process simulated using
Aspen Plus V11.

The study investigates the effect of reactor outlet temperature
on selected process outputs while maintaining the specified
conversion and other fixed simulation conditions.

## Temperature Range

The reactor outlet temperatures investigated were:

- 60 °C
- 80 °C
- 100 °C
- 120 °C
- 140 °C

## Key Observations

- Cooler duty changes substantially across the investigated temperature range.
- N-octane component flow remains nearly constant.
- Flash vapour and liquid flow rates show relatively small variations.
- Reboiler duty remains nearly constant.

These observations apply to the specified simulation model and
operating conditions.

## Model Limitations

The reactor uses a specified stoichiometric conversion of 80%
rather than temperature-dependent reaction kinetics.

Consequently, the study evaluates the response of the simulated
process under the selected conditions; it does not establish
how temperature affects actual reaction kinetics.

The results also depend on the selected thermodynamic model,
recycle configuration, and separation specifications.
