# Ethylene and Isobutane to N-Octane: Aspen Plus Simulation

## Project Overview

This project investigates a simplified n-octane production process
using Aspen Plus V11.

The model represents the reaction using a stoichiometric reactor
and examines the effects of reactor outlet temperature on selected
process outputs.

## Software

- Aspen Plus V11
- WPS Spreadsheets

## Components

- Ethylene
- Isobutane
- N-octane

## Simplified Reaction Representation

2 C2H4 + C4H10 -> C8H18

This is a simplified stoichiometric representation. It is not a
validated industrial reaction mechanism or kinetic model.

## Sensitivity Analysis

Reactor outlet temperatures investigated:

- 60 °C
- 80 °C
- 100 °C
- 120 °C
- 140 °C

The recorded outputs include octane component flow, flash vapour
flow, flash liquid flow, heater duty, cooler duty, reboiler duty,
and condenser duty.

## Model Limitations

The reactor uses a specified ethylene conversion of 80%.
Therefore, the model does not independently predict temperature-
dependent reaction kinetics or conversion.

Results should be interpreted within the assumptions of the
simulation and should not be treated as validated industrial
performance data.
